Manual do Usuario - Format Web

Guia inicial das telas do Format Web, criado a partir da estrutura atual do front-end React, do back-end format-web e da Format API.

Versao inicial: 12/08/2026 Ultima atualizacao: 17/08/2026 Fonte editavel: docs/manual-usuario-format-web.md Aplicacao: Format Web

Visao Geral

O Format Web permite criar, importar, editar e processar layouts Format. O usuario trabalha com projetos, documentos, componentes visuais, assets e arquivos de dados.

/dashboardGestao de projetos: criar, importar, abrir, baixar, renomear e excluir.
/project/editorEditor visual de layouts, paginas, propriedades, camadas, componentes e envios.
/processingProcessamento de layouts e dados para geracao de PDFs.
/login e /registerAcesso local, SSO e cadastro de usuarios.

Acesso

Entrar

  1. Abra /login.
  2. Informe email e senha.
  3. Clique em Entrar com conta local.
  4. Quando disponivel, use Entrar com SSO para acesso corporativo.

Criar conta

  1. Abra /register.
  2. Preencha nome, email e senha.
  3. Clique em Criar conta.
  4. Volte ao login e acesse com a conta criada.

Se aparecer a tela Login expirado, clique em Fazer login e entre novamente.

Meus Projetos

Use /dashboard para administrar projetos.

Criar projeto

  1. Clique em Criar Projeto.
  2. Informe o nome do projeto.
  3. Defina a quantidade de documentos.
  4. Ajuste os nomes dos documentos.
  5. Informe a expressao do documento para cada documento.
  6. Use Editor para abrir o editor auxiliar de expressao, se necessario.
  7. Clique em Criar.

Visao de administrador

Usuarios com perfil ADMIN visualizam a tela como Projetos, podem listar/acessar projetos de todos os usuarios e veem o campo Dono no card quando essa informacao estiver disponivel.

Usuarios comuns continuam restritos aos proprios projetos.

Importar legado

  1. Clique em Importar.
  2. Envie um layout .f ou um ZIP contendo um .f.
  3. Inclua recursos e dados relacionados ao projeto.
  4. Clique em Visualizar para conferir paginas e componentes.
  5. Clique em Importar e Abrir.
AbrirAbre o projeto no editor.
Baixar ZIPExporta o conteudo do projeto.
RenomearAltera o nome exibido no painel.
ExcluirRemove o projeto selecionado apos confirmacao.

Editor de Layout

Use /project/editor para montar e manter layouts.

Areas principais

AreaFuncao
Barra superiorSalvar, zoom e atalhos.
CanvasArea visual onde os componentes sao posicionados.
Painel esquerdoAcoes, documento, entrada e dados.
Painel direitoPropriedades, componentes, camadas e paginas.
EnviosUpload, busca e exclusao de arquivos do projeto.

Fluxo recomendado

  1. Configure documento, paginas, expressao do documento e arquivo de dados.
  2. Envie assets necessarios no painel Envios.
  3. Arraste componentes para o canvas.
  4. Selecione cada componente e ajuste propriedades.
  5. Configure textos, campos de saida, imagens, barcode e QR Code nos modais especificos.
  6. Clique em Salvar layout.
  7. Teste o layout na tela de processamento com dados reais ou representativos.

Expressao do documento

A expressao do documento e obrigatoria. Ao configurar, adicionar, duplicar, renomear ou salvar documentos, o sistema avisa se alguma expressao estiver vazia.

Os botoes Editor de expressao abrem um editor auxiliar com funcoes, operadores, condicionais e constantes simples.

Componentes disponiveis

A paleta principal mostra os componentes abaixo. Campos de entrada cadastrados tambem podem ser arrastados quando aparecem na area correspondente.

Texto Imagem Saida Entrada cadastrada Barcode QR Code Fio Linha H Linha V Retangulo

Estruturas legadas reconhecidas apenas pelo parser ou pelo estado interno nao devem ser tratadas como componentes criaveis pelo usuario enquanto nao aparecerem na paleta do editor.

Editar texto

  1. Abra o modal Editar Texto.
  2. Digite ou ajuste o conteudo e use as opcoes de fonte, tamanho, cor, negrito, italico e alinhamento.
  3. Para inserir um campo de saida dentro do texto, use o botao Campo de saida e monte a expressao no Editor de expressao.
  4. Clique em Salvar.
  • O campo de saida inserido no texto aparece como um token visual dentro do conteudo.
  • As teclas de navegacao tratam o token como um elemento unico.
  • Backspace e Delete removem o token inteiro.
  • Um clique seleciona o token para edicao.
  • Duplo clique no token abre o Editor de expressao com a expressao atual.
  • O botao Campo de saida tambem abre o editor para o token selecionado; se nao houver token selecionado, cria um novo no ponto do cursor.

Campo de saida

Use o componente Saida para montar conteudo calculado ou baseado nos dados de entrada.

O Editor de expressao oferece apoio para campos de entrada, funcoes do usuario, funcoes matematicas, constantes, condicionais e texto vazio.

  • A altura do componente acompanha o tamanho da fonte quando o tamanho da fonte for alterado no modal.
  • Abrir e salvar o modal sem alterar o tamanho da fonte preserva a altura atual do componente.
  • O conteudo do campo de saida e exibido em uma unica linha no documento.
  • Quando o texto ultrapassa a largura do componente, o excedente e truncado visualmente no layout.
  • No campo de saida inserido dentro de texto, o controle manual de largura maxima foi removido; a pre-visualizacao usa limite interno e reticencias para conteudo longo.

Boas praticas

  1. Salve apos cada bloco de alteracoes.
  2. Use nomes claros para documentos e campos.
  3. Mantenha os assets dentro do projeto.
  4. Use camadas para selecionar itens sobrepostos.

Processamento

Use /processing para gerar PDFs e acompanhar execucoes.

Novo processo

  1. Clique em Novo processo.
  2. Escolha Projeto salvo ou Novo upload.
  3. Informe o projeto ou envie layout ZIP/layout .f.
  4. Envie o arquivo de dados.
  5. Adicione recursos soltos ou ZIP de recursos, se necessario.
  6. Inicie o processamento e acompanhe a lista.

Status

StatusSignificado
PROCESSINGProcessamento em andamento.
COMPLETEDProcessamento concluido.
FAILED ou ERRORFalha no processamento; revise a mensagem exibida.

PDFs

  1. Em um processo concluido, clique em Ver PDFs.
  2. Selecione um PDF para visualizar.
  3. Use download para salvar o arquivo.

Editor IDE

A rota /project/editor-ide mostra um prototipo visual de editor em estilo IDE, com painel de acoes, componentes, camadas, paginas, propriedades, uploads e canvas central.

Use como referencia de interface ate que o desenvolvimento confirme o uso como fluxo principal.

Recursos Desenvolvidos no Estado Atual

Esta area lista apenas funcionalidades conferidas no codigo atual do front-end e do format-web.

Configuracao do formulario/papel

O editor abre Configurar formulario pela barra superior ou pelo painel Acoes.

PapelCarta, Oficio, A4, A3 ou personalizado.
UnidadePixels ou milimetros.
RotacaoRetrato, paisagem e opcoes invertidas.
ImpressaoSimples, duplex eixo horizontal ou duplex eixo vertical.

Arquivo de dados e registro

A tela possui tamanho do registro, uso/tamanho de cabecalho, nome do arquivo, procurar arquivo e opcao para pedir o nome do arquivo na impressao.

A configuracao do registro inclui tamanho fixo, tamanho variavel com delimitador, delimitadores, limite por quantidade de campos e contagem de campos mestre/detalhe.

Campos de entrada

A tela mostra grupo, nome, posicao, tamanho e indice. As acoes visiveis sao navegar entre registros, novo, alterar, copiar, colar, excluir e fechar.

Funcoes, variaveis e DLL

O painel Acoes abre funcoes e variaveis do usuario. O backend possui endpoints para carregar a DLL padrao e enviar DLL do projeto.

/api/default-user-function-dll /api/upload-user-function-dll LTRIM RTRIM TRIM UPPER LOWER

Imagens, logos e assets

O painel Envios lista, busca, envia e exclui assets do projeto. Uploads comuns ficam em uploads/{nome-do-arquivo}.

O envio especifico de logo usa /api/upload-logo, salva em logos/{logoId}/{nome-do-arquivo} e retorna a ocorrencia com o nome do arquivo entre aspas.

Atualizacao de 17/08/2026: logotipos legados dentro de textos sao normalizados com mais cuidado para preservar a ocorrencia correta e evitar gravacao incorreta da letra L como nome de imagem.

Linhas e retangulos

A paleta atual permite criar linha horizontal, linha vertical e retangulo. O painel de propriedades permite alterar tipo, espessura, cor, posicao e tamanho.

Elipse pode existir em estruturas internas/importadas, mas nao aparece como item separado na paleta atual.

Download ZIP do projeto

Em Meus Projetos, o download chama /api/download-project e gera ZIP com a ultima versao do .f e assets dentro da pasta assets/.

Compatibilidade com .f legado

Arquivos .f sao importados pelo parser legado e convertidos para JSON. Como algumas estruturas podem nao ter tela completa no Format Web, valide importar, conferir, salvar, baixar o ZIP e reabrir no ambiente de compatibilidade.
